# Delta Core

Delta Core is a Discord bot for Delta Air Lines on ROBLOX.

Its planned responsibilities include:
- Staff allocations
- Staff briefing sheets
- Core operational systems
- Departure announcements
- Roblox ranking workflows
- Additional airline operations tooling as needed

## Planned Stack

- Node.js
- TypeScript
- Discord.js
- Supabase
- Oracle Cloud Always Free for 24/7 hosting

## Project Structure

- `src/` bot source code
- `work/` local planning notes and drafts
- `outputs/` user-facing exported artifacts if needed later

## Getting Started

1. Copy `.env.example` to `.env`
2. Fill in the Discord and Supabase values
3. Run `npm install`
4. Run `npm run dev`

## Notes

This repository is the starting point for the Delta Core brand-specific bot project.
